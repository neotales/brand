# Neotales Brand

Official Neotales brand assets.

## Primary mark

[`assets/logo.png`](assets/logo.png) is the primary Neotales mark. Use it when a single
logo is needed.

```
https://github.com/neotales/brand/raw/main/assets/logo.png
```
